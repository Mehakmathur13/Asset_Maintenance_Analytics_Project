# Asset Maintenance & Inventory Analytics Dashboard

Portfolio project demonstrating data cleaning, Excel/Power Query, SQL analysis, KPI reporting and interactive BI-style dashboarding.

## Stack
Microsoft Excel, Power Query, SQL (SQLite), Python, Pandas, Plotly, Streamlit, Power BI-ready data.

## Workflow
Raw Data → Cleaning & Validation → SQL Analysis → KPIs → Dashboard → Insights

## Run
pip install -r requirements.txt
streamlit run app.py

The dataset is synthetic operational data and contains no real or sensitive military information.
